# Changelog

All notable changes to Remy are documented here. The project follows semantic versioning after the first stable release; alpha APIs may still change between prereleases.

## 0.1.0-alpha — unreleased

### Added

- Publish-ready `@remy-ai/core`, `@remy-ai/webmcp`, and `@remy-ai/react` packages with ESM output and TypeScript declarations.
- Inferred Standard Schema action definitions, replaceable policy, generic grants, readable receipts, and exact or compensating recovery.
- Headless WebMCP registration with unsupported-browser handling, partial-failure reporting, and abort cleanup.
- Versioned bounded journal stores and a stable React external-store hook.
- Morrow WebMCP demonstration and an engine-driven document-action homepage example.
- Clean-fixture tarball verification and push/pull-request CI.

### Changed

- Replaced repository-clone installation messaging with the prepared npm package flow.
- Reduced the homepage to a literal product explanation, interactive proof, recovery model, quickstart, open-source status, and final CTA.

### Removed

- Placeholder CLI and its intentionally failing root command.
- Morrow imagery from the homepage and README.
